## 📌 Project Overview

This project presents an interactive **Customer Segmentation & Sales
Performance Dashboard** built in **Microsoft Excel**. It analyzes
customer behavior, sales trends, product performance, profitability, and
regional insights using Pivot Tables, Pivot Charts, Slicers, and
advanced Excel functions.

## 🎯 Objectives

-   Analyze sales performance
-   Understand customer segmentation
-   Track monthly sales trends
-   Identify top-performing products
-   Compare regional performance
-   Support business decision-making

## 🛠 Tools Used

-   Microsoft Excel
-   Pivot Tables
-   Pivot Charts
-   Slicers
-   Timeline
-   Conditional Formatting

## 📂 Dataset

The dataset contains approximately **1,000 retail sales records**
with: - Customer Information - Product Information - Sales & Profit -
Discount - Payment Mode - Region & Category

## 📊 Dashboard KPIs

-   Total Sales
-   Total Profit
-   Total Orders
-   Total Customers
-   Average Order Value
-   Profit Margin

## 📈 Dashboard Visualizations

-   Monthly Sales Trend
-   Sales by Region
-   Profit by Category
-   Sales by Category
-   Customer Segment Analysis
-   Payment Mode Distribution
-   Top Products
